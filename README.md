# Ops Intelligence

Sistema web para gerenciamento e acompanhamento de solicitações operacionais, desenvolvido como projeto de portfólio em Dados e Programação.

## Objetivo

Centralizar o registro e o acompanhamento de demandas operacionais, permitindo consultar solicitações, atualizar status, monitorar prazos de atendimento (SLA) e visualizar indicadores de desempenho.

## Tecnologias utilizadas

- Google Apps Script (JavaScript)
- HTML e CSS
- Google Sheets
- Git e GitHub

## Funcionalidades — v0.3

- Cadastro de solicitações com identificador automático
- Consulta, pesquisa e filtros
- Visualização detalhada de solicitações
- Atualização de status, conclusão e reabertura
- Cálculo e classificação de SLA
- Dashboard com indicadores operacionais
- Interface responsiva

## Regras de SLA

Os prazos são calculados em horas corridas, de acordo com a prioridade:

| Prioridade | Prazo |
|---|---|
| Crítica | 4 horas |
| Alta | 8 horas |
| Média | 24 horas |
| Baixa | 72 horas |
